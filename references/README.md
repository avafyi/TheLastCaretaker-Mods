# References

Only provenance, links, hashes, and original research notes are tracked. Do not commit third-party source, game binaries/assets, encryption keys, mappings, dumps, or disassembly. Downloaded study material is never a distributable dependency by default.

- `manifest.json`: inspected source versions, URLs, local paths, and SHA-256.
- `downloads/`: ignored public samples and author documentation, read-only research.
- `dumps/`, `extracted/`, `decompiled/`: ignored future runtime/asset research.
- Research conclusions and limits: `../ops/topics/modding-research.md`.

No blanket reuse permission was established for the downloaded sample repositories; author/API metadata reported no SPDX license. Study behavior and implement original code unless a relevant license or permission is established.
